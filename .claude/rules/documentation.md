# FilingLens Documentation Rules

- Repository docs and code comments are in English.
- `docs/PROJECT_PHASES_AND_TASKS.md` is the atomic implementation SSOT.
- `docs/TASKS.md` is the progress/verification ledger.
- `docs/SEC_DATA_CONTRACT.md` defines official source/access/provenance assumptions.
- `docs/EVALUATION.md` defines the quality benchmark and release metrics.
- Update architecture/diagrams whenever interfaces, lineage, evidence flow or state flow change.
- Update deployment/runbook when configuration or operations change.
- Never mark a task complete before code + tests + DoD are verified.
